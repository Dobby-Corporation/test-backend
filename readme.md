# Онлайн-тестирование с проверкой Python-кода

## Запуск

Ниже приведена инструкция по запуску приложения:
1. Локальное окружение:

```
# Инициализация окружения
py -m venv .venv

# Активация окружения
.\.venv\Scripts\Activate.ps1
```

2. Установка библиотек:

```
pip install -r requirements.txt
```

3. Определение переменных окружения. Нужно скопировать `.env.example` в `.env` и задать переменным значения.

4. Миграция БД

```
py manage.py migrate
```

5. Запуск сервера:

```
py manage.py runserver 80
```

## Административная панель

Прежде чем попасть в административную панель, необходимо создать суперпользователя:
```
py manage.py createsuperuser
```

В консоле попросят ввести новые креды, их ввод нужно будет повторить в `http://localhost/admin`. После авторизации панель будет доступна по ссылке: `http://localhost/panel`
